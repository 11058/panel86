Карточка

Карточка может занимать несколько клеток. Крупное — то, на что смотрят издалека: климат, уровень бака, медиа.

Полоса на карточке показывает яркость света — как в Bubble Card.

Если ничего не задать, окно соберётся само по типу карточки — для света яркость, для шторы вверх-стоп-вниз и так далее. Здесь можно собрать своё.

Вычисляет Home Assistant, панель только показывает результат. Все шаблоны раскладки уходят одним запросом раз в полминуты — отдельный запрос на карточку означал бы десяток рукопожатий на каждое обновление.

Маленькие круглые кнопки справа на карточке. Если места не хватает, панель убирает их по одной — имя важнее.

Несколько сцен или сценариев в один ряд. По отдельной карточке на каждую сцену уходит вся страница, а нажимают их редко.

Выберите карточку на экране или нажмите пустую клетку, чтобы добавить.
