# Редактор раскладки

Один самодостаточный HTML-файл. Ни сборки, ни зависимостей, ни интернета.

## Как пользоваться

1. Открыть `editor/index.html` в браузере (двойным щелчком).
2. Вписать адрес панели, например `10.1.20.115:8080`.
3. **Загрузить с панели** — забрать текущую раскладку.
4. Править: страницы, сетка, карточки, тема.
5. **Отправить на панель** — экран перестроится за доли секунды.

Без панели под рукой работают **Открыть файл** и **Сохранить в файл**:
раскладку можно готовить заранее и держать в git рядом с конфигом.

## Почему превью выглядит как панель

Превью считает сетку по той же арифметике, что и прошивка: отступ 12,
зазор 12, шапка 46, пересчёт из 720 × 720 в размер окна. Цвета типов,
перевод состояний и подсветка включённого — те же правила, что
в `components/panel_ui/panel_ui.cpp`.

Значения в превью демонстрационные — те же, что показывает демо-режим
прошивки, когда Home Assistant недоступен.

> Это осознанное дублирование правил в двух местах. Настоящее решение —
> собрать LVGL в WebAssembly и рисовать превью тем же движком, что
> и на панели, пиксель в пиксель. Пока правила простые, дублирование
> дешевле; как только появятся свои виджеты под каждый тип — надо будет
> переходить на WASM, иначе превью начнёт врать.

## Что нужно от панели

Редактор открывается с локального файла, то есть с другого источника,
поэтому панель отдаёт заголовки CORS и обрабатывает предварительный
запрос `OPTIONS`. Это уже сделано в `panel_ui`.

| | |
|---|---|
| `GET /layout.json` | забрать текущую раскладку |
| `POST /layout.json` | проверить, сохранить, перестроить экран |

Присланное проверяется **до** записи: испорченный JSON не затирает
рабочую раскладку, панель отвечает `422`.
