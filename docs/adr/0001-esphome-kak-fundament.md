# ADR-0001. ESPHome как фундамент, свой рантайм-UI поверх

**Статус:** принято · 27.08.2026

## Контекст

Существующие прошивки для этой платы делятся на две группы, и обе упираются
в потолок:

- `alaltitov/Waveshare-ESP32-P4-86-Panel-ETH-2RO`, DarkForge UI, BETTA,
  HomeTiles — пишут весь стек с нуля: сеть, провижининг, OTA, протокол с HA,
  драйверы. Шесть слоёв чужой работы переписаны заново, и на UI ресурса
  не остаётся. DarkForge вдобавок закрыт, BETTA заглохла.
- `chrisdunnname/esphome-p4-86-panel-eth-2ro-lvgl` — чистый ESPHome. Всё
  работает, но настройка это **9 888 строк YAML** с фиксированными слотами
  (`lights1..6`, `controls1..6`, `scenes1..6`) и пересборкой на каждую правку.

Второй вариант — не преувеличение, а измеренный факт: это реальный размер
файла в репозитории.

## Решение

Берём ESPHome фундаментом, но **не как язык описания интерфейса**.

Раскладка становится данными: JSON в LittleFS, который интерпретирует наш
внешний компонент и рисует через LVGL.

## Что это даёт

Из девяти слоёв своими остаются три:

| Слой | Чей |
|---|---|
| Ethernet, Wi-Fi через esp-hosted | ESPHome |
| Провижининг, OTA, логи | ESPHome |
| Протокол и реестр устройств HA | ESPHome |
| Драйверы: DSI, GT911, реле, RS485 | ESPHome |
| Интеграция LVGL, буферы, PPA | ESPHome |
| Голос, presence, Modbus, камеры | ESPHome |
| **Раскладка UI** | **наш** |
| **Редактор раскладки** | **наш** |
| **Привязка сущностей в рантайме** | **наш** |

Плюс то, чего нет ни у одного конкурента и что достаётся почти даром:
локальный фолбэк реле, голосовой ассистент на встроенных микрофонах,
presence-радар по RS485, Modbus.

## Цена

- Зависимость от чужого темпа: пресет дисплея, `esp32_hosted` и
  производительность LVGL на P4 развиваются не нами.
- Внешний компонент придётся держать в согласии с API ESPHome.
- Минимальная версия 2026.7.0 — на старом ESPHome не соберётся.

## Отвергнутые варианты

**Чистый ESPHome.** Три нижние строки таблицы не закрываются никогда.
Годится как конфиг для себя, не годится как продукт.

**Своя прошивка с нуля.** Путь, на котором умерли DarkForge и BETTA.
Шесть слоёв чужой работы за свой счёт.
