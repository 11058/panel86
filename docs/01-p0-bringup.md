# P0 — «Живое железо и цифры»

Цель фазы — не интерфейс, а **числа**. Пока их нет, любое архитектурное
решение ниже по стеку принимается вслепую.

Своего кода в этой фазе нет и быть не должно: только стоковый ESPHome.

---

## Порядок работ

### 1. Проверить, что конфиг вообще собирается

```bash
cp firmware/secrets.yaml.example firmware/secrets.yaml   # заполнить
esphome config  firmware/panel86-p0.yaml                 # синтаксис и пины
esphome compile firmware/panel86-p0.yaml                 # реальная сборка
```

> **Конфиг ни разу не компилировался.** Он собран из проверенного рабочего
> конфига `chrisdunnname/esphome-p4-86-panel-eth-2ro-lvgl` и wiki Waveshare,
> но имена опций и синтаксис LVGL могли разойтись с вашей версией ESPHome.
> Минимальная версия — 2026.7.0. Первое расхождение чините здесь, а не на плате.

### 2. Прошить по USB и увидеть картинку

```bash
esphome run firmware/panel86-p0.yaml --device /dev/cu.usbmodem*
```

Признаки успеха по возрастанию: пошёл лог по UART → зажглась подсветка →
появился текст → реагирует тач.

Если экран чёрный, а лог идёт — почти наверняка `esp_ldo` (канал 3, 2.5 В).
Без него не поднимается PHY MIPI-DSI.

### 3. Снять базовые числа

Все приборы уже в конфиге и выезжают в HA как diagnostic-сущности:
свободная куча, свободный PSRAM, время цикла, температура SoC, время работы.

Кнопка «Запустить бенчмарк» гоняет 120 полных перерисовок экрана и печатает
в лог кадры в секунду. Число грубое — важна не абсолютная величина, а
**сравнение между настройками**.

### 4. Прогнать матрицу настроек

Меняем по одному параметру и записываем в таблицу ниже.

| # | `color_depth` | Доля буфера | Ускорение PPA | к/с | Время цикла, мс | Свободный PSRAM |
|---|---|---|---|---|---|---|
| 1 | 16 | 25 % | нет | | | |
| 2 | 16 | 25 % | да | | | |
| 3 | 16 | 50 % | да | | | |
| 4 | 16 | 100 % | да | | | |
| 5 | 24 | 25 % | да | | | |
| 6 | 24 | 50 % | да | | | |

Полный кадр 720×720: **1,04 МиБ** при 16 битах, **1,55 МиБ** при 24.
Двойная буферизация в 16 битах — около 2 МиБ из 32 МиБ PSRAM. Места хватает
с запасом; узкое место — не объём, а полоса пропускания PSRAM.

> Имена опций ускорения (`use_ppa` и доля буфера) уточнить по документации
> вашей версии: они появились недавно, в рамках работы над производительностью
> LVGL на P4 (esphome/esphome#16873). В `board.yaml` они намеренно не выставлены.

### 5. Проверить сеть — оба профиля

Ethernet (профиль по умолчанию):

```yaml
packages:
  net: !include packages/net-ethernet.yaml
```

Wi-Fi через C6 — **отдельная сборка, отдельные сутки наблюдения**:

```yaml
packages:
  net: !include packages/net-wifi.yaml
```

Что искать в логе: `Dropping packet(s) from stream`, `Failed to push data to
rx queue`, повторные `Association Leave`. Это известная проблема
(esphome/esphome#10956, ровно эта плата). Если воспроизводится — Ethernet
становится не «рекомендацией», а требованием.

### 6. Проверить локальный фолбэк

Кнопка «Реле 1» на экране переключает реле напрямую, минуя Home Assistant.

**Тест:** выдернуть сетевой кабель → нажать кнопку на экране → реле должно
щёлкнуть. Если не щёлкает — это блокер, а не косметика: выключатель, который
перестаёт работать при падении сервера, продавать нельзя.

### 7. Тепловой тест — в настоящей коробке

Собрать в подрозетник, закрыть, дать поработать **два часа** на рабочей
яркости. Снять температуру SoC в начале и в конце.

| | Температура SoC |
|---|---|
| Через 1 мин после загрузки | |
| Через 30 мин | |
| Через 120 мин | |
| Через 120 мин при подсветке 20 % | |

Разница между последними двумя строками — это цена яркости, и она же
обоснование того, чтобы гасить экран при отсутствии людей.

В `board.yaml` подсветка ограничена сверху `max_power: 0.8` именно поэтому.

### 8. Физика

- [ ] Влезает ли RJ45 в вашу коробку? Нужно **≥ 35 мм**, при 33–35 мм —
      коннектор с коротким корпусом.
- [ ] Замерить реальную глубину имеющихся подрозетников.
- [ ] Если планируется профиль B (панель вместо выключателя) — где физически
      разместится модуль AC/DC? Скорее всего нужна коробка ≥ 60 мм.

## Критерий выхода из P0

Фаза закрыта, когда:

1. Таблица настроек заполнена и выбрана рабочая комбинация.
2. Прокрутка списка субъективно плавная (проверяется съёмкой на 120 к/с
   и подсчётом кадров, а не на глаз).
3. Ethernet держит соединение сутки без переподключений.
4. Реле щёлкает при выдернутом кабеле.
5. Температура через два часа в закрытой коробке известна.

Если пункты 1–2 не вытягиваются ни при каких настройках — это разговор
об изменении концепта (меньше анимаций, 16 бит, частичные буферы), и лучше
его провести сейчас, а не через полгода.
